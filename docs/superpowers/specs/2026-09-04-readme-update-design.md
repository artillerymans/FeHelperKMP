# FeHelperKMP README 更新设计

## 背景

当前 README 仍是 Kotlin Multiplatform 初始化模板，未说明项目的实际目标和开发状态。

## 目标

将 README 更新为中文项目说明，使读者能够快速了解：

- FeHelperKMP 是一个面向 Web 和 Desktop 的前端工具集合。
- 项目参考 [FeHelper](https://fehelper.com/) 的工具方向。
- 当前仅完成项目初始化，尚未实现任何可用工具。
- 后续将逐项开发并加入各类前端工具。

## 内容结构

README 按以下顺序组织：

1. 项目名称与定位。
2. 当前状态，明确暂无已实现功能。
3. 开发计划，只描述逐项加入工具的方向，不承诺具体顺序和时间。
4. 技术栈与支持平台。
5. 工程目录说明。
6. Desktop 和 Web 的运行命令。
7. 参考项目说明，避免暗示与 FeHelper 存在官方关联。

## 范围边界

- 不列出尚未确认的工具清单。
- 不添加完成度、发布日期、截图或下载地址。
- 不修改应用代码、构建配置和现有运行命令。
- 不声称当前项目已具备可用功能。

## 验证

- README 全文使用中文，技术名词和命令保持原文。
- 所有相对路径和外部链接格式正确。
- README 陈述与当前仓库状态一致。
- Markdown 格式检查无错误。
